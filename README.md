# Cinema Management System (Java)
This repository contains a **Cinema Management System** developed as a **second-year Computer Science group project** using **Java**.
The goal of this project was to design and implement a simple cinema management application that demonstrates object-oriented programming principles and basic data management. The system allows users to:
* 🎬 Add new movies to the cinema.
* 🗑️ Remove existing movies.
* 🎟️ Reserve seats for movie screenings.
* 📋 View the list of available movies.
This project was developed collaboratively as part of a university assignment, with each team member contributing to the design and implementation of the system.
## Technologies Used
* Java
* Object-Oriented Programming (OOP)
* Collections (where applicable)
* Console-based user interface
